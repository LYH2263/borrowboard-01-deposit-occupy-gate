# Borrowboard · 邻里借用

上架 → 借出通过 → 归还；单物件同时仅一笔在借，含逾期判定。

占用档：开档（预览，物品仍停可借栏、loans 不增行）→ 确认借出（占用档+在借行+items.status 同事务落地，失败整体回滚）。
钉死的口径：未确认占用**占住**可借额度——同物直接借出/再开占用一律 409，全库仅此一套，禁止双活。
数量非正、脏数据（data_quality≠clean）确认失败且现场保持确认前。
